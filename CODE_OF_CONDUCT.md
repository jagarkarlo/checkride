# Code of conduct

Nostekon follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions focused on
the work. Harassment and personal attacks are not tolerated in issues, pull
requests or any other project space.

Report unacceptable behaviour privately to the maintainer,
[@jagarkarlo](https://github.com/jagarkarlo). Reports are handled
confidentially.
