> **Pre-alpha:** Checkride can validate drill specifications and evaluate recorded DrillRun evidence. It does not execute restores, establish evidence provenance or certify recovery.

Checkride is an open-source project for testing recovery of Kubernetes applications, including their data. Explore the [product overview](/), [system design](/product/) and [evidence model](/evidence/) before using the [local walkthrough](/start/).

## Start a local session

In one terminal, start the Go validation API:

```bash
go run ./cmd/checkride-api
```

In another, start the interactive Studio:

```bash
cd studio
npm ci
npm run dev
```

Open `http://127.0.0.1:5173`. Import or edit a JSON drill, run validation, inspect errors or warnings, and download the edited file. The Studio sends the document only to the local API. It does not connect to a cluster.

The acknowledged-write ledger can compute exact RPO from test data today. Automatic restore orchestration, isolation and evidence reports are planned. The [source repository](https://github.com/jagarkarlo/checkride) is temporarily private during a security cleanup; this local site remains available for review.

The current Go evaluator also builds RTO/RPO reports from captured DrillRun JSON, exposed by the local API and `checkride-report` command. The [roadmap](/roadmap/) separates those implemented report calculations from the still-planned restore orchestrator.
