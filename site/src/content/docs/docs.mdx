> **Pre-alpha:** The validator checks a drill specification. Checkride does not yet execute a restore or certify recovery.

Checkride is an open-source project for testing recovery of Kubernetes applications, including their data. Start with the local validator, then use the [verification levels](/levels/) to understand which evidence a restore would need to establish.

## Start a local session

In one terminal, start the Go validation API:

```bash
go run ./cmd/checkride-api
```

In another, start the interactive Studio:

```bash
cd studio
npm ci
npm run dev
```

Open `http://127.0.0.1:5173`. Import or edit a JSON drill, run validation, inspect errors or warnings, and download the edited file. The Studio sends the document only to the local API. It does not connect to a cluster.
